# EduPath-AI User Guide

1. Open the app.
2. Enter a topic, audience, duration, difficulty and learning goal.
3. Select Demo / Mock for a no-key demonstration or Gemini API for AI generation.
4. Click Generate Course.
5. Review Curriculum, Lessons, Assessments and Validation.
6. Download Course_Package.zip.

The package includes PDF, JSON, Markdown and validation outputs.
