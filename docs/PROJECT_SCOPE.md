# Project Scope

## MVP
- Streamlit interface
- Orchestrator
- Four specialized agents
- Structured schemas
- Validation / feedback loop
- PDF and ZIP export
- Tests
- Deployment documentation

## Out of scope for MVP
- Accounts
- Mandatory email delivery
- Mandatory participant API-key entry
- Multi-provider orchestration
- LMS integration
- Student analytics

These are future extensions only.
