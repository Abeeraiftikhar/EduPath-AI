# EduPath-AI Interface Design System

The interface is based on the supplied Sahulat AI visual reference, adapted for EduPath-AI.

## Primary palette
- Primary blue: #2563EB
- Primary dark: #1D4ED8
- Deep navy: #172554
- Text: #0F172A
- Muted text: #64748B
- Soft blue: #EFF6FF
- Pale background: #F8FBFF
- White: #FFFFFF
- Border: #E2E8F0
- Preview border: #CFE0FF
- Success: #059669
- Warning: #D97706

## Layout principles
- No visible sidebar.
- Wide centered desktop layout.
- Rounded white header card.
- Minimal navigation row.
- Large left-aligned hero.
- Product preview card on the right.
- Blue primary CTAs.
- Generous whitespace.
- Responsive behavior for narrower screens.
