# EduPath-AI User Guide

1. Open the app and click **Tell us about yourself** (or **Try a sample profile**).
2. Enter a topic, audience, duration, difficulty and learning goal.
3. Select **Demo / Mock** for a no-key demonstration or **Gemini API** for AI generation.
   If Gemini is unavailable, demo output is shown with a notice.
4. Optional: tick **Demonstrate self-correction** to watch the Quality agent catch a flaw and the agents fix it.
5. Click **Generate Course** and watch each agent report its progress.
6. Review the **Curriculum** (prerequisites, roadmap, modules), **Lessons**, **Assessments** (correct MCQ answers highlighted) and **Validation** (per-check checklist).
7. In **Export**, download `Course_Package.zip`, or just the PDF or Markdown.
8. Use **New course** to start over.

The ZIP contains `Complete_Course.pdf`, `Complete_Course.md`, `Lessons.md`, `Answer_Key.md`,
`Curriculum.json`, `Assessments.json` and `Validation_Report.json`.

AI-generated content should be reviewed by an instructor before classroom use.
