# Hackathon Demo Script (about 4 minutes)

### 1 - Problem
"Creating a complete course by hand needs curriculum design, lesson writing, assessments, answer keys, rubrics and quality checking."

### 2 - Input
Click **Try a sample profile** (Python for Bioinformatics / Undergraduate / Intermediate), set Duration to **4 Weeks**.
Tick **Demonstrate self-correction**.

### 3 - Generate
Click **Generate Course**. Narrate the live progress: Curriculum Architect -> Content Creator -> Assessment Agent -> Quality Agent.
Point out that the Quality agent returns **FAIL (70%)** on the first pass and a **Regeneration** step then fixes it.

### 4 - Inspect
- **Curriculum**: roadmap timeline follows the chosen duration.
- **Lessons**: notes, examples, exercises, case study.
- **Assessments**: correct MCQ answer highlighted, rubrics on assignments.
- **Validation**: 10-check checklist, score, and the issues that were fixed automatically.

### 5 - Adaptability
Click **New course**, choose **1 Week** / **Advanced**: fewer modules and stronger objectives. Output is not a fixed template.

### 6 - Export
Download `Course_Package.zip` (or the PDF) and show the files. A ready-made copy is in `examples/`.

### Fallback
If the network fails, use Demo / Mock mode. If the live app (https://edupath-ai-pakangels.streamlit.app/) is down, run locally or show `examples/Sample_Course_Package.zip`.
